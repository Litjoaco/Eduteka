¿Cómo funcionan los Roles Base?
Al completar el onboarding, el sistema clona automáticamente los roles marcados como Rol Base usando el modelo RolColegio (es_base=True). Cada institución puede personalizar sus propios roles sin afectar esta plantilla global.
Crear Nuevo Rol Base
Este rol se clonará automáticamente a todos los colegios en onboarding.
Eliminar Rol
